# Website photos

Keep website photos in this folder. The hero carousel uses `hero-01.webp` through `hero-09.webp`; the bridal gallery uses `bridal-01.webp` through `bridal-09.webp`.

For more gallery photos, use category names in filenames, such as `ceremony-01.webp`, `prewedding-01.webp`, `haldi-01.webp`, `engagement-01.webp`, `maternity-01.webp`, `baby-01.webp`, or `product-01.webp`. Add each new image to its category in `photography.html`. The homepage preview is selected separately in `index.html`.
